Jetzt in Word starten

  1. Schließen wählen.
  2. Microsoft Word starten und ein Dokument öffnen.
  3. Unter Start → Add-Ins den Footnote-Checker auswählen. Je nach Word-Version: Weitere Add-Ins / Meine Add-Ins / Entwicklertool-Add-Ins.
  4. Eine Dokumentkopie zunächst im Modus Analyse prüfen.

Keine Terminaleingabe nötig. Dein Mac muss nicht neu gestartet werden.

Ein neues Webcode-Update wird separat auf dem Dienst bereitgestellt. Ein neues Installationspaket allein aktualisiert diesen Dienst nicht.
